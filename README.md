# blocke

[![CI](https://github.com/Glatzel/blocke/actions/workflows/ci.yml/badge.svg)](https://github.com/Glatzel/blocke/actions/workflows/ci.yml)
[![codecov](https://codecov.io/gh/Glatzel/blocke/graph/badge.svg?token=NLTQSALvc9)](https://codecov.io/gh/Glatzel/blocke)

**blocke** is a small experimental playground for embedded systems development.
It’s designed for quick prototyping, testing ideas, and sharing reusable building blocks for low-level work.
